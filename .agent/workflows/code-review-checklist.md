## 🔍 회계 엔진 수정 시 필수 확인 사항

### 1. 현금 흐름 계산 (`accountingEngine.ts`)
- [ ] 은행 간 이체(보통예금 ↔ 현금)가 순현금에 영향을 주지 않는가?
- [ ] VAT 포함 여부가 일관되게 처리되는가? (`amount + vat`)
- [ ] `cashInflow`와 `cashOutflow`가 대칭적으로 계산되는가?

### 2. 재무 지표 (`forecastingEngine.ts`)
- [ ] `currentCashBalance`가 `financials.cash`에서 직접 가져오는가? (중복 계산 방지)
- [ ] 예측 로직이 과거 데이터를 **중복 집계**하지 않는가?
- [ ] 시나리오별 배율(Optimistic: 1.15, Conservative: 0.9)이 올바른가?

### 3. UI 표시 (`Dashboard.tsx`, `AIForecastPanel.tsx`)
- [ ] 금액 포맷팅이 `formatCurrency()` 또는 `formatCLevel()` 사용하는가?
- [ ] 음수 금액이 올바르게 표시되는가? (절댓값 + 부호)
- [ ] 로딩 상태가 있는가? (사용자가 계산 중임을 알 수 있도록)

### 4. 데이터 무결성
- [ ] `status === 'Approved'` 필터링이 적용되었는가?
- [ ] 마감된 기간(`isDateLocked`)의 데이터 수정이 차단되는가?
- [ ] 중복 ID 체크가 있는가? (특히 자동 생성 전표)

## 🚨 런타임 검증 (자동)

다음 경고가 콘솔에 나타나면 **즉시 확인 필요**:

1. **🚨 [CRITICAL ANOMALY] Cash balance: ₩XXX**
   → 현금 잔액이 100억 초과 (계산 오류 가능성 높음)

2. **⚠️ [SUSPICIOUS] No cash outflow detected**
   → 거래가 많은데 지출이 0원 (로직 오류)

3. **🚨 [INVARIANT VIOLATION] Negative P/L**
   → 매출/비용이 음수 (차대변 반대로 계산됨)

## 📋 수정 후 필수 테스트

### 시나리오 1: 은행 간 이체
```
차변: 보통예금 1,000,000
대변: 현금 1,000,000
→ 현금 잔액 변동: 0원 (✅ 정상)
```

### 시나리오 2: 매출 발생
```
차변: 현금 5,000,000
대변: 매출 5,000,000
→ 현금 잔액: +5,000,000원 (✅ 정상)
→ 매출: +5,000,000원 (✅ 정상)
```

### 시나리오 3: 비용 지출
```
차변: 급여 3,000,000
대변: 보통예금 3,000,000
→ 현금 잔액: -3,000,000원 (✅ 정상)
→ 비용: +3,000,000원 (✅ 정상)
```
