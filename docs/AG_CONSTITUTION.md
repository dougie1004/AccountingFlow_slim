# 🛡️ Antigravity 통제 운영 헌법 (AG Constitution v1.0)

## 제1조: 승인 없는 실행 금지
- AI는 자동 실행 엔진이 아닌 사고 도구다.
- 모든 파일 수정 전 **[계획 -> 대상 목록 -> Diff]**를 제시하고 인간의 명시적 승인을 받는다.

## 제2조: 세션 분리 원칙
- `ARCH`, `CORE`, `TEST`, `REFACTOR`, `DOC` 목적에 따른 세션을 엄격히 분리한다.
- 혼합 세션으로 인한 판단 오염 및 토큰 폭증을 방지한다.

## 제3조: 모델 고정 및 쿼터 통제
- 단일 모델 사용 및 자동 라우팅 금지.
- **Context Slimming**: 300줄 이하 분할 전달, 로그 제거, 핵심 함수 위주 분석.
- 세션당 토큰 예산(5k~8k) 준수.

## 제4조: 자동 실행 범위 제한
- 허용: 테스트 초안, 주석, 리팩토링 제안.
- 금지: 핵심 회계 로직(VAT, Closing, Risk 공식)의 임의 수정.

---

## 🏗️ AccountingFlow 단계별 사용 가이드 (현재: 안정화 단계)

### Phase A — 결정론 강화 (Focus)
- 테스트 케이스 자동 생성
- Edge Case 및 Sign Convention 검증
- 12월 Spike 테스트 생성

### Phase B — Closing 안정화
- Closing 체크리스트 및 Panic 조건 정의

### Phase C — 리스크 산정 보정
- 통계적 시뮬레이션 및 가중치 민감도 분석 보조 (공식 결정은 인간)
