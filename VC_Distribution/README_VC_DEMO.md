# 🚀 AccountingFlow: CFO Intelligence & Financial Integrity System
### VC 투자 검토용 데모 가이드 (v0.1.0)

본 가이드는 **AccountingFlow**의 핵심 가치와 데모 실행 방법을 안내합니다. 본 시스템은 단순한 회계 소프트웨어를 넘어, AI 기반의 재무 전략 수립과 데이터 무결성 보증을 목표로 합니다.

---

## 📦 설치 및 실행 방법

1.  **설치 파일 실행**: 동봉된 `AccountingFlow_Setup.exe`를 더블 클릭하여 설치를 진행해 주세요.
2.  **보안 경고 관련**: 아직 공식 서명 전인 데모 버전이므로, Windows 보호 창이 뜨면 `추가 정보` -> `실행`을 눌러주시면 됩니다.
3.  **로그인**: 별도의 계정 생성 없이 메인 화면으로 진입 가능하도록 설정되어 있습니다.

---

## 🎯 5분 안에 확인하는 핵심 투자 포인트 (Wow Points)

### 1. 3개년 전략 시뮬레이션 (The Future View)
*   **방법**: 메인 대시보드 상단의 **[3개년 시뮬레이션 RUN]** 버튼을 클릭하세요.
*   **임팩트**: 단순한 선형 예측이 아닌, SaaS 수익 모델(Churn, CAC, LTV)과 정부보조금 회계 로직이 결합된 현실적인 3년치 재무 상태표가 즉시 생성됩니다.

### 2. 데이터 무결성 검증 (Level 4 Integrity)
*   **메뉴**: `데이터 무결성 검증 센터 (Integrity Center)`
*   **임팩트**: 모든 재무 데이터는 지문(SHA-256)으로 봉인되어 있습니다. 1원이라도 조작될 경우 시스템이 즉시 감지하여 차단하는 'Zero-Trust' 회계 아키텍처를 확인해 보세요.

### 3. 실시간 BvA 분석 (Operational Control)
*   **메뉴**: `운영 계획 (Operation Plan)`
*   **임팩트**: 설정한 예산 대비 실제 지출(Actual)의 편차를 실시간으로 추적하여, 스타트업의 현금 연소율(Burn Rate)을 어떻게 관리하는지 보여줍니다.

## 💡 VC를 위한 핵심 인사이트
*   **SaaS Metrics 기반**: 모든 매출 추정은 사업계획서 상의 실제 목표와 연동되어 있습니다.
*   **현금 무결성**: 자본금과 실제 현금 흐름을 분리하여 '가짜 흑자'를 방지하는 정교한 엔진이 탑재되어 있습니다.
*   **확장성**: 추후 AI 경영 조언 시스템(Observation Mode)과의 연동을 통해 자동화된 CFO 자문 서비스로 확장 가능합니다.
